# Vehicle Service Management System

A web-based Vehicle Service Management System developed using Java, JDBC, Servlets, JSP, HTML, CSS and MySQL.

## Technologies Used

- Java
- JDBC
- Servlets
- JSP
- HTML
- CSS
- MySQL
- Apache Tomcat
- Maven

## Features

- Admin Login
- Dashboard
- Customer Management
- Vehicle Management
- Vehicle Service Management
- Service History
- Service Status Management
- Customer and Vehicle Relationship
